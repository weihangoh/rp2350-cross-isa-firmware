# Build Instructions

This project builds a reset-mediated Arm/RISC-V firmware demonstrator for Raspberry Pi RP2350 / Pico 2 W.

The project has three firmware components

- `arm_worker/` - Arm worker image for core1
- `riscv_worker/` - RISC-V worker image for core1
- `arm_host/` - Arm host image for core0

The final UF2 to flash is always produced by the host build

```text
arm_host/build/arm_host.uf2
```

## Tested Environment

These instructions assume Windows Command Prompt or the VS Code Command Prompt terminal.

Example project path

```text
F:\demo_pico2w
```

Required tools

- Raspberry Pi Pico SDK
- Pico SDK toolchain
- CMake
- Ninja
- Python 3
- Git

## Generated Files

The host embeds generated files

```text
arm_host/bcdemo_program.h
arm_host/worker_arm_blob.h
arm_host/worker_riscv_blob.h
```

These are generated during the build flow and are normally not committed.

`bcdemo_program.h` is generated by the XISA assembler.

`worker_arm_blob.h` is generated by building `arm_worker`.

`worker_riscv_blob.h` is generated by building `riscv_worker`.

Because `arm_host` embeds all three generated headers, the build order matters.

## Build Order

For a full clean build

```text
1. Assemble bytecode with xisa.
2. Build arm_worker.
3. Build riscv_worker.
4. Build arm_host.
```

The host must be built last.

## Protection Levels

```text
0 = plaintext bytecode
1 = encrypted bytecode
2 = encrypted bytecode + authenticated state
```

Bytecode assembly rule

```text
Protection level 0:
  assemble without --encrypted

Protection level 1 or 2:
  assemble with --encrypted
```

## Stable Demo Build: Level 2 Protected Checksum

This is the main stable protected demo path.

```cmd
cd /d F:\demo_pico2w\xisa
python -m xisa.cli assemble examples\checksum.bc -o ..\arm_host\bcdemo_program.h --encrypted
cd ..\arm_worker
rmdir /s /q build
cmake -G Ninja -S . -B build -DBCDEMO_PROTECTION_LEVEL=2 -DBCDEMO_TRACE_DECODED_INSTRUCTIONS=off
cmake --build build
cd ..\riscv_worker
rmdir /s /q build
cmake -G Ninja -S . -B build -DBCDEMO_PROTECTION_LEVEL=2 -DBCDEMO_TRACE_DECODED_INSTRUCTIONS=off
cmake --build build
cd ..\arm_host
rmdir /s /q build
cmake -G Ninja -S . -B build -DBCDEMO_PROTECTION_LEVEL=2 -DBCDEMO_TRACE_DECODED_INSTRUCTIONS=off -DBCDEMO_OUTPUT_PROFILE=instrumented -DBCDEMO_ROUTE_MODE=alternate -DBCDEMO_WAIT_FOR_SERIAL_ON_START=0
cmake --build build
```

Flash

```text
F:\demo_pico2w\arm_host\build\arm_host.uf2
```

Expected result

```text
verification result       = PASS
actual output32           = 0x00000044
expected output32         = 0x00000044
protection_level          = 2
```

## CRC32 Builds

CRC32 is useful as a larger stress workload.

If the workers have already been built for the selected protection level, switching from `checksum.bc` to `crc32.bc` only requires

```text
1. Reassemble bytecode.
2. Rebuild arm_host.
```


## Useful Host Flags

### Output Profile

Instrumented output

```cmd
-DBCDEMO_OUTPUT_PROFILE=instrumented
```

Program-blind output

```cmd
-DBCDEMO_OUTPUT_PROFILE=program-blind
```

Use `instrumented` for debugging and development.

Use `program-blind` for anti-extraction style demonstrations.

### Route Mode

Available route modes

```text
alternate
random-free
no-repeat
```

Recommended stable demo mode

```cmd
-DBCDEMO_ROUTE_MODE=alternate
```

Randomized routing mode

```cmd
-DBCDEMO_ROUTE_MODE=random-free
```

### Serial Behavior

Start execution without requiring the serial console to be open

```cmd
-DBCDEMO_WAIT_FOR_SERIAL_ON_START=0
```

Wait for serial before starting

```cmd
-DBCDEMO_WAIT_FOR_SERIAL_ON_START=1
```

### Pause Between Instruction Batches

Pause after every 200 completed bytecode instructions

```cmd
-DBCDEMO_PAUSE_EVERY_INSTRUCTIONS=200 -DBCDEMO_PAUSE_MS=100 -DBCDEMO_PAUSE_GPIO=15
```

Example host build with pause enabled

```cmd
cd /d F:\demo_pico2w\arm_host
rmdir /s /q build
cmake -G Ninja -S . -B build -DBCDEMO_PROTECTION_LEVEL=2 -DBCDEMO_TRACE_DECODED_INSTRUCTIONS=off -DBCDEMO_OUTPUT_PROFILE=instrumented -DBCDEMO_ROUTE_MODE=alternate -DBCDEMO_WAIT_FOR_SERIAL_ON_START=0 -DBCDEMO_PAUSE_EVERY_INSTRUCTIONS=200 -DBCDEMO_PAUSE_MS=100 -DBCDEMO_PAUSE_GPIO=15
cmake --build build
```

## LED Indicators

Default GPIO usage

```text
GP12 = heartbeat / activity
GP13 = final PASS
GP14 = final FAIL
GP15 = pause active
```

Expected successful completion

```text
GP13 on
GP14 off
```

Expected failure

```text
GP13 off
GP14 on
```

## Rebuild Rules

### Changed only the `.bc` bytecode program

Rebuild only the host

```text
1. Run xisa assemble.
2. Rebuild arm_host.
```

### Changed protection level

Rebuild everything

```text
1. Rebuild arm_worker.
2. Rebuild riscv_worker.
3. Rebuild arm_host.
```

### Changed code in `common/`

Rebuild everything

```text
1. Rebuild arm_worker.
2. Rebuild riscv_worker.
3. Rebuild arm_host.
```

### Changed only host behavior

Examples

```text
serial wait flag
route mode
output profile
pause settings
LED settings
```

Rebuild only

```text
arm_host
```

## Cleaning

Clean all build directories

```cmd
cd /d F:\demo_pico2w
rmdir /s /q arm_worker\build
rmdir /s /q riscv_worker\build
rmdir /s /q arm_host\build
```

Delete generated headers

```cmd
cd /d F:\demo_pico2w
del arm_host\bcdemo_program.h
del arm_host\worker_arm_blob.h
del arm_host\worker_riscv_blob.h
```

## Verifying Build Flags

Check worker flags

```cmd
cd /d F:\demo_pico2w\arm_worker
findstr /n "BCDEMO_PROTECTION_LEVEL" build\build.ninja
cd ..\riscv_worker
findstr /n "BCDEMO_PROTECTION_LEVEL" build\build.ninja
```

Check host flags

```cmd
cd /d F:\demo_pico2w\arm_host
findstr /n "BCDEMO_PROTECTION_LEVEL" build\build.ninja
findstr /n "BCDEMO_ROUTE" build\build.ninja
findstr /n "BCDEMO_OUTPUT_PROFILE" build\build.ninja
```

## Verifying Generated Headers

```cmd
cd /d F:\demo_pico2w\arm_host
dir bcdemo_program.h
dir worker_arm_blob.h
dir worker_riscv_blob.h
findstr /n "worker_arm_blob_LEN" worker_arm_blob.h
findstr /n "worker_riscv_blob_LEN" worker_riscv_blob.h
```

For protection level 1 or 2, confirm the program header is encrypted

```cmd
findstr /n "BCDEMO_PROGRAM_ENCRYPTED" bcdemo_program.h
```
